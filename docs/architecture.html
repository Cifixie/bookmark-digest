→ Request Flows

1 Ingest a URL

  1. Browser → POST /sources (Cognito auth)
  2. ingest-url Lambda validates the URL
  3. Queries UrlIndex GSI on SourcesTable for dedup
  4. Fetches content via Firecrawl API
  5. SHA-256 hashes the content
  6. Conditional Put — `attribute_not_exists(contentHash)` for idempotency
  7. Sets status = "embedding" → triggers DynamoDB Stream
  8. Returns { sourceHash, status: "new"|"existing" }

2 Generate Embedding

  1. DynamoDB Stream fires on INSERT with NEW_IMAGE
  2. embed-source Lambda receives the new source image
  3. Sends content to Bedrock titan-embed-text-v2:0
  4. Receives 1536-dim normalized vector
  5. Update item: sets embedding, model, timestamp, status → "ready"

3 Generate a Digest

  1. Browser → POST /digests with { sourceHash, digestGoal, modifiers }
  2. generate-digest checks SourceHashIndex GSI for existing pending digest
  3. If none: creates row with status = "pending"
  4. GetCommand fetches source content from SourcesTable
  5. Assembles prompt: goal template + modifiers + catalog block descriptions + content
  6. Calls Bedrock Claude via Vercel AI SDK generateObject()
  7. Validates output against digestBlockSchema
  8. Update to status = "done", stores DigestBlock[]

4 Fetch Sources & Digests

  1. GET /sources/:hash → fetch-source → GetCommand(contentHash)
  2. GET /digests/:id → fetch-digest → GetCommand(id)
  3. GET /digests?sourceHash=:hash → Query(SourceHashIndex) — lists all digests for a source
  4. GET /digest-goals → digest-goals — static config, no DB access

✦ Key Design Decisions

No Aurora → DynamoDB from day one

Aurora Serverless v2 on the AWS Free Plan requires "express configuration" — a manual CLI step CloudFormation can't automate. DynamoDB eliminates all of this: fully CDK-managed tables, on-demand billing (25GB/25RCU/WCU always-free), no VPC, no secrets, no cold starts.

Stream-triggered embedding, no manual invoke

DynamoDB Streams on the SourcesTable automatically invoke embed-source on INSERT. This replaces the previous pattern of ingest-url directly invoking embed-source via Lambda's InvokeFunction API — eliminating a cross-Lambda IAM grant and the risk of invocation failures being silently swallowed.

Brute-force similarity search (adequate at personal scale)

Losing pgvector's HNSW index is accepted — at personal-bookmark scale (dozens to low thousands of sources), a Scan + in-Lambda cosine similarity is fast and cheap. Revisit with OpenSearch Serverless only when scan latency becomes noticeable.

Shared DynamoDB helper: lib/dynamo.ts

Extracted from the previously-deferred C.3 task — a DynamoDBDocumentClient wrapper with typed helpers (get, put, update, query, scan) shared across all 5 data-touching Lambdas. Provides genuine reusability that the ARN-parameterized RDS helper never quite achieved.

Conditional puts for idempotent inserts

PutCommand with ConditionExpression: "attribute_not_exists(contentHash)" replaces Aurora's INSERT ... ON CONFLICT DO NOTHING. ConditionalCheckFailedException signals the source already existed — matching the previous Lambda's dedup-then-branch behavior without any explicit conflict handling.

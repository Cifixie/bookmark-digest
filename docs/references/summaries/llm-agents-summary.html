Beginner's Summary

LLM-Powered Autonomous Agents

What if an AI could plan, remember, and use tools — just like a person solving a problem? This page explains exactly that, in plain language.

Original article by Lilian Weng →
The Big Idea

An LLM (like ChatGPT) is normally just a chatbot — you ask, it answers. An autonomous agent goes further: it uses the LLM as its "brain" but also gives it the ability to plan multi-step tasks, remember things, and use external tools (search the web, run code, call APIs). The result is an AI that can tackle long, complex goals on its own.

The 3 core components

Every autonomous agent is built from three building blocks working together.

🧠

1. Planning

The ability to break a big goal into smaller steps, think ahead, and correct mistakes.

  • Chain of Thought — think step by step before answering
  • Tree of Thoughts — explore multiple paths, pick the best
  • ReAct — alternate between reasoning and taking action
  • Reflexion — notice when something went wrong and try again differently
💾

2. Memory

Agents need to remember things beyond what fits in a single conversation.

  • Short-term — the current conversation context (limited)
  • Long-term — a database the agent can search and retrieve from (like a notebook)
  • Sensory — raw inputs like images or text turned into numbers the AI understands
🔧

3. Tool Use

Connecting the LLM to the outside world so it can actually do things, not just talk.

  • Web search — look up current information
  • Code execution — run programs and get results
  • External APIs — call databases, services, etc.
  • Other AI models — use specialist models for specific tasks

Planning — how agents think

These are the main techniques agents use to reason through problems.

Planning
Chain of Thought (CoT)

Tell the AI to "think step by step." Instead of jumping to an answer, it works through the problem like showing your work in math class. Simple but powerful.

Planning
Tree of Thoughts

Like CoT but branches out — the AI explores several possible directions at once and evaluates which path looks most promising, then continues down that route.

Planning
ReAct

A loop: Reason → Act → Observe → Repeat. The agent thinks about what to do, does it, sees the result, then thinks about the next step. Very natural and human-like.

Planning
Reflexion

The agent keeps a memory of past mistakes. When something fails, it writes a note to itself ("that didn't work because…") and uses that lesson in future attempts.

Memory — how agents remember

Think of it like human memory — there are different types for different purposes.

Memory
Sensory Memory

Raw inputs (text, images) converted into numbers. Like your eyes taking in light — the very first step before any understanding happens.

Memory
Short-Term (Working)

Everything in the current conversation window. The AI can only "see" so much text at once — this is a hard limit. Like keeping a few things in mind at once.

Memory
Long-Term (Vector Store)

An external database the agent can search. Information is stored as vectors (lists of numbers) and retrieved by similarity. Like a searchable notebook that never fills up.

Tool use — how agents take action

These frameworks show how researchers have connected LLMs to real-world tools.

Tools
MRKL

Routes questions to specialist "expert" modules — some AI-based, some traditional programs (like calculators). The LLM decides who to ask.

Tools
Toolformer

A model trained to figure out when and how to call external APIs by itself — no manual rules needed. It learned tool use from examples.

Tools
HuggingGPT

Uses ChatGPT as a "manager" that selects the right specialist AI model from HuggingFace for each sub-task. Like a boss delegating to the right employee.

Real-world examples

Projects that put these ideas into practice.

AutoGPT

Give it a goal, it figures out the steps, uses tools (files, web, code), and keeps going until done — with minimal human input.

GPT-Engineer

Describe a software project in plain English. It asks clarifying questions, then writes an entire codebase from scratch.

ChemCrow

A chemistry agent with 13 specialist tools. Can plan drug synthesis and lab experiments — validated by real chemists.

Generative Agents

25 AI "people" living in a virtual world. They remember events, form plans, gossip, and even organize parties — all emergent behavior.

Current challenges

Agents are impressive but still have real limitations to be aware of.

⚠️ Limited context window

The AI can only hold so much text in memory at once. Long tasks require clever tricks to compress or retrieve relevant history — it's a fundamental bottleneck.

⚠️ Poor long-term planning

When something unexpected happens mid-task, agents struggle to adapt their overall strategy. They're much better at short plans than 20-step sequences.

⚠️ Unreliable output format

LLMs sometimes return text in the wrong format or forget to follow instructions. Real systems need a lot of error handling and output parsing to stay stable.

Key Takeaway

An LLM alone is a smart text predictor. Give it planning, memory, and tools and it becomes an agent that can pursue goals, learn from mistakes, and interact with the real world. We're still in early days — but the building blocks are already here.
